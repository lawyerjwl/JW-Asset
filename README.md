# LIFE ROAD 시세 서버

대시보드에 실시간 시세를 공급하는 작은 백엔드입니다.
`대시보드 → 이 서버(/quotes) → Yahoo Finance` 구조로, 브라우저 CORS·API 키 문제 없이 시세를 받아옵니다.

---

## 1. 로컬에서 먼저 실행해 보기

Node.js 18 이상이 필요합니다. 터미널에서 이 폴더로 이동한 뒤:

```bash
npm install
npm start
```

`http://localhost:8787/quotes` 를 브라우저에서 열어 아래 형태의 응답이 나오면 정상입니다.

```json
{ "fx": 1432, "asof": "2026-07-01T...", "quotes": { "TLT": 126540, "VOO": 731200 } }
```

---

## 2. 인터넷에 배포하기 (대시보드에서 쓰려면 필요)

로컬 주소(localhost)는 대시보드가 접근할 수 없으므로, 무료 호스팅에 올립니다. 가장 쉬운 두 가지:

**Render (추천)**

이 폴더에 `render.yaml`(Blueprint)이 포함되어 있어 설정이 자동입니다.
1. github.com 에 이 폴더 전체를 저장소로 올립니다.
2. render.com → New → **Blueprint** → 해당 저장소 선택 → Apply.
   (Blueprint 대신 New → Web Service 를 써도 됩니다. 그 경우 Build: `npm install`, Start: `npm start`, 환경: Node 로 직접 지정.)
3. 배포되면 `https://xxxx.onrender.com` 형태의 주소가 나옵니다.

**Railway / Fly.io / Cloudtype(국내)** 도 동일하게 `npm start` 로 동작합니다.

> 무료 플랜은 일정 시간 미사용 시 잠들 수 있어, 첫 호출이 몇 초 느릴 수 있습니다.

---

## 3. 대시보드에 연결

1. 대시보드 → **설정** 탭 → **시세 서버 URL** 에 배포 주소(예: `https://xxxx.onrender.com`)를 입력합니다.
2. **투자·거래내역** 탭 → 현재가 카드 → **↻ 시세 새로고침** 을 누르면, 서버가 돌려준 시세로 현재가와 환율이 채워집니다.
3. URL을 비워두면 예전처럼 공개 데이터(해외 ETF만) 방식으로 동작합니다.

---

## 4. 종목 추가 / 국내 자산

`server.js` 상단의 `MAP` 에서 종목을 관리합니다.

- **미국 ETF·주식** (`source: "yahoo"`): 심볼 그대로 (`TLT`, `VOO`, `QQQ` …).
- **국내 상장 ETF** (`source: "naver"`): 네이버 금융 종목코드 그대로 (`379800`, `0080X0` 같은 alphanumeric 코드 포함). 이미 KODEX 미국S&P500·SOL 미국S&P500미국채혼합50 이 등록되어 있습니다.
- **MMF (KODEX 머니마켓액티브 488770)**: 대시보드에 '보유수량 1개(총액)'로 들어 있어 주당 시세로 곱하면 값이 틀어집니다. **실제 보유 주(株) 수를 확정**한 뒤 `MAP` 에서 주석을 해제하세요.
- **BANK · 특정 미국 국채**: 단일 공개 시세가 없어 자동 대상 제외 → 대시보드에서 **수동 입력**.

### (선택) 국내 펀드·연금까지 자동화하려면
한국투자증권 등 **증권사 OpenAPI**에 계좌 인증 후, 펀드 기준가/평가금액을 받아오는 코드를 `server.js` 에 추가하면 됩니다. 이 경우 앱키/시크릿 발급과 토큰 관리가 필요하므로, 원하시면 그 부분을 별도로 붙여 드리겠습니다.

---

## 주의
- Yahoo Finance는 비공식 엔드포인트라 간헐적 지연·차단이 있을 수 있습니다(개인용으로는 대체로 안정적).
- 시세는 실시간 체결가가 아니라 지연/종가 기준일 수 있습니다.
- 이 서버는 시세만 중계하며, 대시보드의 금융 데이터는 서버로 전송되지 않습니다.
